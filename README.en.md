# Smart Dorm · Backend

Personal Java backend portfolio project derived from [youlai-boot](https://gitee.com/youlaiorg/youlai-boot), by 有来开源组织. Original Apache-2.0 license and source attribution are preserved; see [LICENSE](LICENSE).

Building, room and student CRUD and operation permissions exist. Accommodation is schema-only; check-in/check-out transactions, concurrency controls and an AI Agent are **not implemented**. Full integration still needs an isolated database and Redis.

See the [Chinese README](README.md) for current setup, private environment variables, SQL initialization order, test evidence and publication status. No real database rows or credentials are distributed. The intended private GitHub repository has not yet been created because GitHub CLI/login is unavailable.
